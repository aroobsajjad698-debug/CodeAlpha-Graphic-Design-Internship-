# CodeAlpha Graphic Designing Internship — Task Submission

**Submitted by:** Aroob Sajjad

This repository contains the source files for three completed tasks for the CodeAlpha Graphic Designing Internship: a Logo Redesign, a Typography Practice poster, and a User Interface Design flow. Each task shares a unified editorial design language — asymmetric composition, restrained color, and a single hand-touched imperfection per piece.

## Structure

```
.
├── task1-logo-redesign/
│   ├── logo-redesign.svg      # source
│   └── preview.png            # rendered preview
├── task2-typography-practice/
│   ├── typography-poster.svg  # source
│   └── preview.png            # rendered preview
└── task3-ui-design/
    ├── screen-1-dashboard.svg     # source
    ├── screen-2-task-detail.svg   # source
    ├── preview-screen1.png        # rendered preview
    └── preview-screen2.png        # rendered preview
```

## Viewing the designs

Each `.svg` file can be opened directly in any browser, or in Figma/Illustrator by dragging it into the canvas. The `.png` files are flattened previews for quick viewing on GitHub.

## Tools referenced

Adobe Illustrator, Figma, and Canva — in line with the tools recommended in the CodeAlpha task brief. These SVGs represent the design concepts in code form; final production was modeled after Illustrator/Figma workflows.

## Tasks

| Task | Concept |
|------|---------|
| 1. Logo Redesign | Brutalist Warmth — architectural geometry softened by one organic, hand-touched detail |
| 2. Typography Practice | Brutalist Editorial Poster — extreme scale contrast, a shout interrupted by a whisper |
| 3. User Interface Design | Editorial Interface — magazine-style asymmetric grid instead of a generic SaaS dashboard |
